# نصب دستیار PROTEOUS · کیمیائی آکادمی

این صفحه فقط راهنمای نصب است. خود دستیار در مخزن خصوصی آکادمی است و فقط برای دانشجوهای دعوت‌شده نصب می‌شود.

## قبل از شروع
- اپ دسکتاپ **Claude** با تب **Code** (اشتراک Pro یا Max). دانلود: [claude.com/download](https://claude.com/download)
- حساب **GitHub** که نام کاربری‌اش را به آکادمی داده‌ای و آکادمی دعوتت کرده است. لازم نیست ایمیل دعوت را باز کنی.

## نصب
1. روی دسکتاپ یک پوشه‌ی خالی بساز، مثلاً `Videos`. ویدیوهایت از این به بعد اینجا ساخته می‌شوند.
2. اپ Claude را باز کن، برو تب **Code** و همین پوشه را انتخاب کن. اگر پرسید به پوشه اعتماد داری، **Trust** را بزن.
3. این پیام را کپی کن و بفرست:

```
دستیار PROTEOUS کیمیائی آکادمی رو برام نصب کن. راهنمای نصب: https://raw.githubusercontent.com/Kimiaei-Academi/proteous-setup/main/INSTALL.md
```

4. هر بار Claude اجازه خواست، **Allow** را بزن. یک بار هم برای ورود به GitHub یک پنجره و مرورگر باز می‌شود؛ Claude فارسی و قدم‌به‌قدم می‌گوید چه کار کنی.

آخر کار، Claude می‌گوید چطور شروع کنی.

اگر جایی گیر کردی، از صفحه‌ات عکس بگیر و برای آکادمی بفرست.

## نسخه‌ی Codex (ChatGPT)
اگر به‌جای Claude از **Codex** (اپ ChatGPT، Codex CLI یا افزونه‌ی ویرایشگر) استفاده می‌کنی، همان قدم‌ها را برو، فقط در Codex این پیام را بفرست:

```
دستیار PROTEOUS کیمیائی آکادمی رو برام نصب کن. راهنمای نصب: https://raw.githubusercontent.com/Kimiaei-Academi/proteous-setup/main/CODEX.md
```

هر بار Codex اجازه خواست، تأیید کن. آخر کار Codex را کامل ببند و باز کن و بنویس «سلام».
